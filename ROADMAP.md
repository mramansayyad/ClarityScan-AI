# Roadmap - ClarityScan AI

This document outlines the planned features and milestones for ClarityScan AI.

## Phase 1: MVP (Completed)

- [x] Document parsing and text extraction.
- [x] Integration with Gemini 2.5 Flash via Genkit.
- [x] Light/Dark mode support.
- [x] Basic UI for document upload.

## Phase 2: Enhanced Features (Q2 2026)

- [ ] Support for multi-page PDF processing.
- [ ] Custom extraction schemas (allow users to define what to extract).
- [ ] Export data to CSV, JSON, and Google Sheets.
- [ ] History and search for processed documents.

## Phase 3: Enterprise Readiness (Q3 2026)

- [ ] User authentication and RBAC (Role-Based Access Control).
- [ ] Team workspaces and sharing.
- [ ] API access for external integrations.
- [ ] Webhook support for processed documents.

## Phase 4: Advanced AI (Q4 2026)

- [ ] Custom model fine-tuning for specific document types (e.g., invoices, medical records).
- [ ] Support for multi-modal extraction (extracting charts and tables as structured data).
- [ ] Autonomous agents for complex document workflows.
